# Project Images

This folder contains screenshots from the **Bagel Shop Operating System** project.

These images showcase different operational modules included in the digital SOP system and demonstrate the organization, structure, and usability of the documentation.

## Included Screenshots

- **Hand Washing Procedure**
  - Standardized hand hygiene instructions following food safety practices.

- **Master Temperature Table**
  - Temperature reference guide for food safety monitoring.

- **Prep Logs**
  - Daily food preparation records used to ensure consistency and traceability.

- **System Codes & Glossary**
  - Reference guide explaining operational codes, abbreviations, and terminology.

- **Uniform Checklist**
  - Employee appearance and uniform verification checklist.

- **Walk-in Layout**
  - Visual organization of the walk-in cooler to improve storage consistency and efficiency.

## Purpose

These screenshots are provided for demonstration purposes only and represent the structure and design of the operational system. Business-specific information has been removed where appropriate.
