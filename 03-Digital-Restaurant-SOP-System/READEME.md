# Bagel Shop Operating System

A responsive digital Standard Operating Procedure (SOP) system designed for bagel shops.

## Project Overview

This project standardizes restaurant operations by providing digital documentation accessible from tablets and mobile devices.

Features include:

- Opening and closing procedures
- Cleaning schedules
- Food safety guidelines
- Equipment operation
- Employee onboarding
- Kitchen checklists
- Digital documentation
