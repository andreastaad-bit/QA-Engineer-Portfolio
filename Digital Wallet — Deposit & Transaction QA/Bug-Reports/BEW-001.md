# BEG-001 — El segundo depósito no puede procesarse correctamente

## Información del defecto

| Campo       | Detalle                                                                                       |
| ----------- | --------------------------------------------------------------------------------------------- |
| Bug ID      | BUG-001                                                                                       |
| Test Case   | TC-015                                                                                        |
| Requirement | MUL-001                                                                                       |
| Título      | El segundo depósito no puede procesarse correctamente después de completar un depósito previo |
| Severidad   | High                                                                                          |
| Prioridad   | High                                                                                          |
| Tipo        | Functional                                                                                    |
| Estado      | Open                                                                                          |

## Descripción

Después de realizar correctamente un primer depósito, el sistema no permite procesar correctamente un segundo depósito realizado inmediatamente después.

## Precondiciones

* Usuario con cuenta activa y autenticada.
* El usuario puede realizar depósitos.
* El primer depósito utiliza un monto válido.

## Datos de prueba

* Depósito A: 100.00
* Depósito B: 200.00

## Pasos para reproducir

1. Iniciar sesión con una cuenta activa.
2. Realizar un depósito de **100.00**.
3. Esperar la confirmación del primer depósito.
4. Iniciar un nuevo depósito por **200.00**.
5. Intentar completar el segundo depósito.
6. Verificar el resultado de la operación.

## Resultado esperado

El segundo depósito debe procesarse correctamente de forma independiente al primer depósito.

Una vez procesado correctamente, el sistema debe reflejar la operación correspondiente y actualizar el balance de acuerdo con el monto depositado.

## Resultado actual

El segundo depósito no se procesa correctamente después de que el primer depósito fue realizado con éxito.

## Impacto

El comportamiento impide realizar depósitos consecutivos y afecta el flujo normal de depósitos múltiples de un usuario.

## Relación con el requisito

Este defecto afecta el requisito:

**MUL-001 — Multiple deposits independently allowed:**
El sistema debe permitir realizar múltiples depósitos de forma independiente.
