# BEW-002 — Los métodos de depósito no están disponibles directamente en la página principal

## Información del defecto

| Campo       | Detalle                                                                          |
| ----------- | -------------------------------------------------------------------------------- |
| Bug ID      | BUG-002                                                                          |
| Test Case   | TC-016                                                                           |
| Requirement | DEP-023                                                                          |
| Título      | Los métodos de depósito no están disponibles directamente en la página principal |
| Severidad   | Medium                                                                           |
| Prioridad   | Medium                                                                           |
| Tipo        | Functional / Usability                                                           |
| Estado      | Open                                                                             |

## Descripción

Los diferentes métodos disponibles para realizar depósitos no se muestran directamente en la página principal de depósitos.

Para acceder a determinados métodos, el usuario debe ingresar a una sección adicional antes de poder seleccionarlos.

## Precondiciones

* Usuario con cuenta activa y autenticada.
* El usuario tiene acceso a la sección de depósitos.

## Datos de prueba

* Monto de depósito: 20.00

## Pasos para reproducir

1. Iniciar sesión con una cuenta activa.
2. Acceder a la cartera digital.
3. Ingresar a la sección de depósitos.
4. Revisar los métodos de depósito disponibles en la página principal.
5. Verificar si los métodos disponibles pueden seleccionarse directamente desde esta página.

## Resultado esperado

Los métodos disponibles para realizar depósitos deben mostrarse directamente en la página principal de depósitos, permitiendo al usuario seleccionar el método correspondiente sin tener que acceder a una sección adicional.

## Resultado actual

No todos los métodos de depósito están disponibles directamente en la página principal.

El usuario debe acceder a otro apartado para encontrar y utilizar determinados métodos de depósito.

## Impacto

El comportamiento añade pasos innecesarios al flujo de depósito y puede dificultar que el usuario encuentre un método de pago disponible.

## Relación con el requisito

Este defecto afecta el requisito:

**DEP-023 — Payment Method Availability:**
Los métodos disponibles para realizar un depósito deben estar visibles directamente en la página principal de depósitos.
