# BUG-008 - Inconsistent Study Session Design Across Multiple Browser Tabs

## Summary

Opening the application in multiple browser tabs results in an inconsistent visual design. One of the tabs displays a different study session layout while the others remain unchanged.

---

## Bug ID

**FMOA-008**

---

## Severity

**Trivial**

---

## Priority

**Low**

---

## Environment

- **Application:** Focus Mode On
- **Website:** https://focusmodeon.lat/
- **Browser:** Opera GX
- **Operating System:** Windows 11
- **Browser Engine:** Chromium 149.0.7827.197

---

## Preconditions

- Opera GX is installed.
- Internet connection is available.

---

## Steps to Reproduce

1. Open https://focusmodeon.lat/ in Opera GX.
2. Open the website in a second browser tab.
3. Open the website again in a third browser tab.
4. Compare the default study session displayed in each tab.

---

## Expected Result

The default study session should display the same layout and visual design across all opened browser tabs.

---

## Actual Result

One of the browser tabs displays a different study session layout, while the remaining tabs display the expected design.

---

## Workaround

Refresh the affected browser tab.

---

## Status

Unresolved
