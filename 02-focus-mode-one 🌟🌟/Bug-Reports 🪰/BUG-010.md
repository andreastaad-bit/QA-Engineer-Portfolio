# BUG-010 - Doodling Session Does Not Start While Browser Tab Is Inactive

## Summary

The application does not automatically transition to the Doodling session while the browser tab is inactive. The session only updates after the user returns to the Focus Mode On tab.

---

## Bug ID

**FMOA-010**

---

## Severity

**Major**

---

## Priority

**Medium**

---

## Environment

- **Application:** Focus Mode On
- **Website:** https://focusmodeon.lat/
- **Browser:** Opera GX
- **Operating System:** Windows 11
- **Browser Engine:** Chromium 149.0.7827.197

---

## Preconditions

- Open the Focus Mode On website.
- Start any study session.

---

## Steps to Reproduce

1. Open https://focusmodeon.lat/.
2. Start a study session.
3. Open another browser tab and continue working there.
4. Wait until the first study block finishes.
5. Return to the Focus Mode On tab.

---

## Expected Result

The application should automatically transition to the Doodling session once the first study block ends, even while the browser tab is inactive. The corresponding visuals, timer, and audio should update automatically.

---

## Actual Result

While the browser tab is inactive, the application does not transition correctly to the Doodling session. The previous visualization may remain on screen, or the Doodling animation starts without updating the background audio. The correct state is only restored after the user returns to the Focus Mode On tab.

---

## Workaround

Keep the Focus Mode On tab active during the study session.

---

## Status

Unresolved
