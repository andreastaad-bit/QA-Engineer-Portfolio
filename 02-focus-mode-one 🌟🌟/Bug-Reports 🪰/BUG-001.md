# BUG-001 - Unable to Switch Between Study Blocks During an Active Session

## Summary

Users cannot switch between different blocks within the same study session while the session is running.

---

## Bug ID

**FMOA-001**

---

## Severity

**Major**

---

## Priority

**High**

---

## Environment

- **Application:** Focus Mode On
- **Website:** https://focusmodeon.lat/
- **Browser:** Opera GX
- **Operating System:** Windows 11
- **Browser Engine:** Chromium 149.0.7827.197

---

## Preconditions

- Open the Focus Mode On website.
- Start any study session.
- Allow the first block to begin playing.

---

## Steps to Reproduce

1. Open the Focus Mode On website.
2. Start a study session.
3. Observe the progress bar.
4. Click on a different study block (Focus, Doodling, or Box Breathing) while the current block is playing.

---

## Expected Result

The selected study block should become active immediately, allowing users to switch between blocks without pausing the current session.

---

## Actual Result

Clicking on another study block has no effect while the session is running. The application continues playing the current block. The only workaround is to pause the session before selecting another block.

---

## Workaround

Pause the current session before selecting a different study block.

---
