# BUG-015 - Study Session Does Not Progress While Browser Tab Is Minimized

## Summary

When the browser tab is minimized, the study session does not automatically transition to the next scheduled block after the current timer ends.

---

## Bug ID

**FMOA-015**

---

## Severity

**Major**

---

## Priority

**Medium**

---

## Environment

- **Application:** Focus Mode On
- **Website:** https://focusmodeon.lat/
- **Browser:** Opera GX
- **Operating System:** Windows 11
- **Browser Engine:** Chromium 149.0.7827.197

---

## Preconditions

- Open the Focus Mode On website.
- Start any study session.

---

## Steps to Reproduce

1. Open https://focusmodeon.lat/ in Opera GX.
2. Start a study session.
3. Minimize the browser window while the session is running.
4. Wait until the current study block reaches its end.
5. Restore the browser window.

---

## Expected Result

The application should continue running in the background. Once the current study block finishes, the next scheduled block should start automatically, updating the timer, audio, and study content accordingly.

---

## Actual Result

While the browser tab is minimized, the timer for the current block finishes, but the session does not transition to the next block. The background audio continues playing, and the study schedule remains on the previous block.

---

## Workaround

Keep the browser tab active during the study session.

---

## Status

Unresolved
