
# 🧪 Test Cases

This folder contains the manual test cases created and executed during the testing phase of the **Focus Mode On** web application.

The objective of these test cases is to validate the application's core functionality, ensure a consistent user experience, and identify defects before release.

---

## 📋 Test Coverage

The test cases cover the application's most important features, including:

- Homepage functionality
- Navigation between study sessions
- Video playback
- Audio controls
- Study session selection
- Doodle sessions
- Box Breathing exercises
- Timer functionality
- Browser compatibility
- Responsive behavior
- Error handling
- User experience

---

## 📄 Test Case Documentation

The complete set of manual test cases is available in the Excel spreadsheet included in this folder.

The document contains:

- Test Case ID
- Test Title
- Preconditions
- Test Steps
- Expected Result
- Actual Result
- Testing Environment
- Execution Status (PASS / FAIL)
- Related Bug Report (when applicable)

---

## 🔗 Traceability

Whenever a test case failed, a detailed Bug Report was created and documented separately in the **Bug Reports** folder.

This allows each failed test to be traced back to its corresponding defect.
